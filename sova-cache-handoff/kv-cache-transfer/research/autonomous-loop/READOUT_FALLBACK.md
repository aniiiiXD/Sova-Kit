# If full-question distillation still fails

This is a proposed fallback, not an implemented or executed experiment. Keep the current task-readout results and the prospective quality gate unchanged. Do not allocate this branch until its trigger is supported by the validation curve.

The current map mixes all KV heads but uses a single depth-aligned source layer for each target layer. Initial fitting minimizes token-level K/V error. Neither feature support nor fitting weights are guaranteed to preserve what receiver attention actually reads. Native256 reduced development KL in19/30articles and made11worse; a lower average is not a universal repair.

The next bounded alternative would hold the selected key maps fixed and fit a query-readout value correction, inspired by the CacheBridge method already reviewed in ../thesis-v1/literature-review.md. Verify the primary body and released implementation before calling anything a reproduction. Primary-body correction: CacheBridge uses the current mapped-branch query state, with fresh query K/V held identical while substituting native target history for the reference readout. It calibrates in layer order and propagates corrected query states before the next layer. Using fully native queries would be a different surrogate. Serving must not consume full native history as a hidden oracle. See https://arxiv.org/html/2609.00891#S4.SS2 and https://arxiv.org/html/2609.00891#A2.

For a target KV head and one of its grouped query heads, let a be the attention weights produced by the frozen mapped keys at the current mapped-branch offline query. Let X be the source value features for translated positions only (all source KV heads concatenated). The value-map readout is (a_translated X)W + sum(a_translated)b. Subtract the explicitly retained native-prefix and native suffix contributions from the native-history substituted attention output at that same query state before fitting W,b. The bias feature is attention mass on translated positions, not a constant1 when only part of the state is translated. Combine both grouped query heads under the same KV-head value map. Weight documents equally and bound update energy; a global token-rich article must not dominate the fit.

This local surrogate does not capture changes in downstream student queries. A correction must subsequently run the real frozen receiver and be selected on the same thirty development articles. No improvement of this proxy alone is success. Do not use acceptance sources for calibration or selection. Preserve the uncorrected candidate as the paired control.

A separate structural branch, only if diagnostic evidence warrants it, is predictive source-layer selection or a small multi-layer feature support. More layers increase mapper parameters, retained state dependencies and online FLOPs. Account for that explicitly rather than enlarging a residual without evidence. These are established method precedents, not novelty claims.

Verified primary details: the readout feature intercept is the mapped attention mass on history; all token rows and grouped query heads share one KV-head correction. Documents receive equal total weight. The paper limits the feature-metric update energy to1%ofinitial value residual energy and folds the correction into exported affine maps. Our all-head/native256extension remains a proposal, not a reproduction.
