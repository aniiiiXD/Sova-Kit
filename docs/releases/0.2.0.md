# SwitchIt 0.2.0

A coordinated release of the Python harness, npm launcher, and companion skill.

## Workflow packages

Recorded agent work can be imported into revisioned events, reconstructed into a graph, reviewed as a workflow contract, exercised with fixed checks, and exported as a skill package. Exports include instructions, the workflow contract, optional fixture cases, a hash manifest, and a fixture verifier.

The release includes GitHub and Aegis evidence adapters, workflow CLI/MCP operations, bounded recipe comparison and local promotion/rollback, a resumable command DAG, and a local evidence review UI. Activity metadata remains separate from executable model/tool traces.

## npm migration

The `switchit-harness` npm package now forwards to a separately installed Python engine. This replaces the old standalone TypeScript implementation. Install Python 3.10+ and Python `switchit-harness>=0.2.0`, then upgrade the npm launcher. Node 20+ is required for the launcher; Node 18+ for the skill installer. Set `SWITCHIT_PYTHON` when selecting a virtual environment.

```sh
python3 -m pip install --upgrade "switchit-harness>=0.2.0"
npm install --global switchit-harness@latest
npx switchit-skill@latest
switchit --version
```

The legacy Python import/map/cases/replay/report commands remain available. The reviewed workflow format is distinct from legacy grouping files. The npm launcher does not automatically install or upgrade Python.

## Boundaries

- Workflow discovery and inferred ordering require review.
- Fixture success measures recorded evidence; it does not prove live portability.
- Provider runtimes call supported models while keeping tools fixture-backed.
- Command runtimes require configured wrappers and explicit execution authorization.
- Native agent wrappers are not bundled. An OpenAI-compatible endpoint alone cannot supply tools, permissions, or environment state.
- The local UI is not a hosted multi-user service. The public website's replay is an illustrative sample.
- No personal traces, environment files, or runtime databases belong in release artifacts.
