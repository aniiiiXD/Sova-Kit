# SwitchUP v0.3.0

SwitchUP records corrections to agent behavior and tests instruction changes against a fixed replay suite.

- **Traces** imports model and tool events, deduplicates captures, records corrections, and pins held-out sessions.
- **Improvement Loop** proposes a revision, runs the active and candidate instructions against the same checks, and supports activation and rollback.

[Python module guide](https://github.com/aniiiiXD/SwitchIt/blob/v0.3.0/docs/python-modules.md) · [SwitchUP setup](https://github.com/aniiiiXD/SwitchIt/blob/v0.3.0/docs/switchup.md)

```sh
python -m pip install https://github.com/aniiiiXD/SwitchIt/releases/download/v0.3.0/switchit_harness-0.3.0-py3-none-any.whl
switchup improve --help
```

The Python library and local interface are included in the wheel. The release was verified with synthetic replay cases and a deterministic model fixture. Connected projects use the model endpoint you configure. This release applies instruction updates.
